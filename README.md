# 云端禅院

一个可点开即玩的网上寺庙 / 云端禅修网页原型。打开链接即可生成专属小沙弥，敲木鱼、盘串、上香、拜佛、求签许愿、供奉本命佛。

**仅供文化娱乐与冥想放松，不涉及真实宗教活动。**

## 在线地址

https://kaba252.github.io/cloud-temple/

## 本地预览

任意静态服务器即可，例如：

```bash
python3 -m http.server 8080
```

加 `?demo=1` 可跳过山门，直接进入大殿（便于调试）。

## 说明

- 单页静态应用，无构建步骤，无后端。
- 修行记录保存在浏览器 `localStorage`。
- 同屏禅修里的其他小沙弥与在线人数为客户端模拟演示。
- 音效与禅境音均由 Web Audio API 合成，不依赖音频素材。
