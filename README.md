# 云端禅院

打开即可进院的网页禅修庭园。当前版在保留全部玩法、同屏与「流畅模式」的前提下，使用 PBR 材质与暮色 HDRI，大雄宝殿按传统格局布置横三世佛，小沙弥沿用第二版圆头小沙弥并加上 PBR 光照。

**在线地址：** https://kaba252.github.io/cloud-temple/

## 在院里可以做什么

点地行走、拖动环顾、双指缩放。走近即可上香、礼拜、撞钟、绕塔、许愿挂红、坐下盘串或敲木鱼。可为自己生成本命佛，与同修同屏云端禅修。真人走 WebRTC 点对点；连不上时会以标注「演示」的小沙弥填满庭院。同浏览器多标签可通过 BroadcastChannel 互见。

仅供文化娱乐与冥想放松，不涉及真实宗教活动，亦不以宗教名义收取任何费用。

## 当前画面

- 石砌地面、朱漆柱、陶瓦、树皮与铜器均为 Poly Haven CC0 的 PBR 贴图
- 大雄宝殿可步入：横三世佛（释迦牟尼居中，阿弥陀、药师分列，阿难与迦叶侍立），供桌、拜垫、十八罗汉、藻井与幡幢均为程序化金色圆雕
- 秋枫、松树与竹林；石灯笼与纸灯笼；香炉青烟；莲池水面反射；暮色 HDRI
- ACES 色调映射、体积感雾气、灯火微弱辉光、落叶粒子
- 光照随本机时间在黎明 / 白昼 / 暮色 / 夜间之间切换
- 小沙弥为圆头比例的自制角色，含行走、趺坐、礼拜、合掌；匾额「大雄宝殿」「云端禅院」居中完整绘制

设置里可开关「流畅模式」（降低阴影、辉光与像素比）。弱设备会自动采用流畅模式。

## 本地预览

任意静态服务器即可，例如：

```
python3 -m http.server 8080
```

然后打开 `http://localhost:8080/`。
