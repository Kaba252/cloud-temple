# 云端禅院

可点开即玩的网上寺庙 / 云端禅修。打开链接即可成为一名小沙弥，在三维禅院里行走、合掌、礼拜、敲木鱼、盘念珠，也可求签、许愿、供奉本命佛。

**仅供文化娱乐与冥想放松，不涉及真实宗教活动。**

## 在线地址

- 当前版本（三维禅院）：https://kaba252.github.io/cloud-temple/
- 第一版二维原型：https://kaba252.github.io/cloud-temple/v1/

## 操作

- 点击地面或 WASD / 方向键行走；拖动旋转视角；滚轮或双指缩放。
- 手机可使用左下虚拟摇杆。
- 底部：合掌、礼拜（单击一拜，长按连磕 108）、木鱼、念珠。
- 走近香炉、钟楼、许愿树、蒲团、宝塔会出现互动提示。绕宝塔走一圈会计数。
- 快捷键：`1` / `E` / 空格 礼拜，`2` 念珠，`3` 合掌，`5` 木鱼。
- 声音默认关闭，可在右上角或设置里打开。

## 本地预览

```bash
python3 -m http.server 8080
```

同屏：同一浏览器下的多个标签页可通过 BroadcastChannel 即时看见彼此。跨设备会尝试 Trystero（WebRTC + 公共 Nostr 信令）。若没有真人同修，院子里会用标注「演示」的模拟沙弥补位。
